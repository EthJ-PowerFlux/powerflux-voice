# PowerFlux Voice

简体中文 | [English](README.en.md)

[下载公开测试版](https://github.com/EthJ-PowerFlux/powerflux-voice/releases/tag/v0.3.0)

按住 Option 说话，松开后把文字填入当前输入框。可以添加常用的人名、公司名和产品名。应用在本机识别语音，不自动发送文字。

## 安装

需要 macOS 13 或更新版本。

1. 从 [Releases](https://github.com/EthJ-PowerFlux/powerflux-voice/releases) 下载对应安装包：M 系列芯片选 `arm64`，Intel Mac 选 `x86_64`。
2. 解压，把 `PowerFlux Voice.app` 放进“应用程序”文件夹，然后打开。
3. 按应用里的说明允许麦克风和辅助功能。麦克风用于录音，辅助功能用于监听 Option 键并把文字填入输入框。
4. 点选一个输入框，按住左侧或右侧 Option 说话，松开后等待文字出现。

0.3.0 是公开测试版，使用本机签名，尚未取得 Developer ID 签名和 Apple 公证。首次打开可能被 macOS 拦截。如果确认下载来源和校验值无误，可以按 [Apple 的说明](https://support.apple.com/en-au/102445) 在“系统设置 → 隐私与安全性”中对这个应用选择“仍要打开”。不需要关闭系统安全保护。

安装包附带识别引擎和模型，首次打开会准备约 900 MB 的本地文件。运行不依赖 Python、Codex 或已安装的 Handy，也不需要 API key。

## 使用

- 按住 Option 录音，松开开始转写。Escape 取消。
- Option 与其他键或鼠标组合使用时会取消本次听写，原来的组合操作继续生效。
- 点菜单栏 PowerFlux 图标，打开“常用词”，每行写一个词，然后保存。删除对应行即可移除。
- 词库合计最多 200 字、50 个词，每词最多 50 字。它用于纠正常用词：中文按同音写法优先匹配，英文由引擎纠正。建议只添加人名和专有词；同音但含义不同的普通词可能被误改。
- 若转写期间切换了应用或输入焦点，结果保留在“复制上次文字”中，避免填入错误的位置。
- 需要开机启动时，在菜单中勾选“开机启动”。

开始识别前会过滤过短或接近静音的录音。环境噪声、混合语言和专有名词仍可能识别有误，发送前请检查文字。

中文输出统一转为简体；纯英文仍保留英文。录音时屏幕底部仅显示一个小声波图标，松开后显示三个处理圆点。详细状态可在菜单栏查看。

首次启动会提前加载本地模型，可能需要半分钟；就绪后才开始接受听写。已在本机用合成语音验证“简体字”和“孩子的哄睡”等例子，但真实口音和噪声环境仍需试用。

## 数据

音频在这台 Mac 上处理，不上传。临时录音在转写完成、取消处理结束或正常退出后删除；异常断电或强制终止可能留下临时文件。最近一次文字只保存在应用内存，退出后清除。

词库保存在本机应用偏好中，引擎和模型位于 `~/Library/Application Support/PowerFluxVoiceDictation/`。它们与原来的 PowerFlux 会议工具、Handy 设置和录音相互独立。

## 测试范围

Apple Silicon 安装包已在 M2 Mac 上通过构建、签名、模型加载、合成语音、简体规范化和词库逻辑检查。Intel 安装包通过交叉构建、架构和解压验签，尚未在 Intel 真机测试。0.3.0 的实际日常听写效果仍在试用验证中。

更新本机签名的测试版后，macOS 可能要求重新允许自动填字。如果应用仍显示“待允许”，请在系统设置中重新启用 PowerFlux Voice 的辅助功能/设备控制权限；系统可能要求 Touch ID 或登录密码。
